## About this project

This is a single-page site built to introduce me, show my work, and make
it easy for potential clients or collaborators to reach out. It's built
entirely with plain HTML, CSS, and JavaScript — no frameworks, no
backend — and hosted for free on GitHub Pages.

## Features

- Dark mode / light mode toggle (remembers your choice)
- Scroll-triggered reveal animations, no external library
- Filterable portfolio grid (Project Management / Web Development / Creative Content)
- Interactive hover-tilt effect on project cards
- Mobile-friendly, responsive layout
- Built with accessibility basics in mind: readable color contrast,
  keyboard navigation, and respect for reduced-motion settings
